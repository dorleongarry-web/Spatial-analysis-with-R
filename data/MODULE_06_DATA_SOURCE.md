# Module 06 — source data and scope

The input raster and vector boundaries are the local example files installed with the R package terra (execution supplied here: terra 1.9.50):

- system.file("ex/elev.tif", package = "terra")
- system.file("ex/lux.shp", package = "terra")

Official package and help: https://rspatial.github.io/terra/

The elevation grid has 90 rows, 95 columns, a 0.008333333 degree resolution and EPSG:4326 coordinates. Elevations are in metres, with valid values from 141 to 547 m in this example. These coarse teaching data do not provide a high-resolution or up-to-date terrain survey. The provenance available from the installed example is not a specification of survey date or elevation accuracy; no such accuracy is claimed in the lesson.

NAME_1 and NAME_2 are source administrative attributes, used only to demonstrate grouping and masking. They are not presented as current administrative divisions.

The mosaic tiles are artificial subdivisions of the same DEM, not independently acquired surveys. Terrain indices are calculated on the original elevation grid. Coarser-grid outputs are explicitly identified as resolution experiments. No extra detail is created by interpolating them back to the original grid.

GeoTIFF outputs are generated by scripts/06-rasters-1.R. PNGs are plot images, not substitutes for spatial raster data. The shaded-relief model receives slope and aspect in radians; its illumination direction and angle are in degrees.
