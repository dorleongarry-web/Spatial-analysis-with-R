Core concepts

A geospatial workflow turns spatial datasets into maps, measurements, and evidence. R supports repeatable operations similar to those performed interactively in QGIS. Keep raw data unchanged and store code and outputs separately.

Hands-on R example

Copy the following script into an RStudio project. Some examples use sample data included with the terra package; others are conceptual illustrations.

# Install once, then load when you work
install.packages(c("terra", "sf"))
library(terra)
library(sf)

# Keep paths relative to your project directory
dir.create("data", showWarnings = FALSE)
dir.create("outputs", showWarnings = FALSE)
dir.create("scripts", showWarnings = FALSE)
