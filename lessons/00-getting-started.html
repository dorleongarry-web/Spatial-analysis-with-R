Getting Started with RStudio and Course Data

Set up your project once and use reliable relative paths in every exercise.

Required before practical exercisesWindows / macOS / LinuxTools: R · RStudio · terra
Start here before running any code. Spatial datasets must be stored on your computer. Uploading datasets to GitHub does not automatically make them available in RStudio. Complete these steps to avoid errors such as [vect] file does not exist.

1 · Download the complete course repository

Open the course repository on GitHub. Choose Code → Download ZIP. Download the complete repository, not a single R script. The ZIP includes the vector datasets for the first exercises and a small preview raster; larger satellite and terrain datasets may be distributed separately.

2 · Extract the ZIP and identify the project root

Extract the ZIP into a folder you can access (for example, Documents/Spatial-analysis-with-R-main). Open it in your file manager and locate the folder containing all three folders: data/, scripts/, and lessons/.

Spatial-analysis-with-R-main/
├── Spatial-analysis-with-R.Rproj  <-- open this file
├── data/
│   ├── vectors/
│   │   └── ne_50m_admin_0_countries.gpkg
│   └── rasters/
│       └── GRAY_50M_SR_OB_preview.tif
├── scripts/
├── lessons/
└── index.html
Common mistake: extraction can produce nested folders: Spatial-analysis-with-R-main/Spatial-analysis-with-R-main/. Open the inner folder if that is where the data/ directory actually exists. Do not assume the outer folder is the correct one.

3 · Open the RStudio project

Double-click Spatial-analysis-with-R.Rproj, or open RStudio and choose File → Open Project and select this file. The working directory should now be the repository root. Avoid hard-coded absolute paths and avoid using setwd() inside teaching scripts.

If the .Rproj file is missing from an older download, open RStudio and choose File → New Project → Existing Directory, then select the folder containing data/.

4 · Check your project before importing data

In the RStudio Console, run the following. The first line checks the current location; the second checks the main GeoPackage used in Module 2.

getwd()
list.files()
file.exists("data/vectors/ne_50m_admin_0_countries.gpkg")

The final command must return TRUE. For a more complete check, run:

source("scripts/00-check-project.R")

↓ Download the project-check script

When the checks pass, try importing and mapping the data:

library(terra)
countries <- vect("data/vectors/ne_50m_admin_0_countries.gpkg")
plot(countries, col = "beige", main = "Natural Earth - countries")

5 · Troubleshooting

The check returns FALSE: run list.files(). If data is absent, you opened the wrong folder or downloaded an incomplete set of files. Locate the folder with data/vectors/, then open its RStudio project.

The data folder exists but the file is missing: run list.files("data/vectors"). Download the full repository again if the original course GeoPackages were omitted.

The first import fails: do not continue to plot(countries), print(countries), or crs(countries) until countries <- vect(...) succeeds.
