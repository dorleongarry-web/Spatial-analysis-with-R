Real course datasets

Download and explore the original course vector layers. Large raster datasets are distributed separately.

Vector datasets

Country boundaries and graticules use WGS 84 (EPSG:4326); the French departmental, geological, mining and structural data mainly use Lambert-93 (EPSG:2154). Check each layer's metadata before analysis.

  • French_NPP.ods
  • dept.gpkg
  • elevation.gpkg
  • litho.gpkg
  • mines.gpkg
  • ne_50m_admin_0_countries.gpkg
  • ne_50m_graticules_10.gpkg
  • struct.gpkg

First R exercise

Open the project root in RStudio, install terra, then run the script below. Results will be saved under outputs/ on your computer.

Download the R script

library(terra)
countries <- vect("data/vectors/ne_50m_admin_0_countries.gpkg")
print(countries)
plot(countries, col = "beige")

Raster data

The source ZIP also includes IGN BD ALTI elevation ASCII tiles, Sentinel-2 imagery (JP2) and a global TIFF raster. These are not included in this website update because of size. Download them from the separately distributed original course archive and retain the data/rasters/ directory structure.

Data provenance: Course data supplied by the site maintainer; source licenses and attribution should be checked before public redistribution.
